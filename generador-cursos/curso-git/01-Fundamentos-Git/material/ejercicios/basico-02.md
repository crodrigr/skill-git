# Básico 02 — Explicar el control de versiones

## Estado inicial

Ninguno: es un ejercicio de análisis y redacción, no requiere terminal.

## Proceso esperado

Responder, con tus propias palabras (sin copiar la definición literal del material):

1. ¿Qué es el control de versiones?
2. ¿Qué problema concreto resuelve? Da un ejemplo distinto al usado en la explicación
   conceptual (por ejemplo, de tu propia experiencia guardando archivos).
3. ¿Qué podría salir mal si un proyecto de código NO usa control de versiones?

## Resultado esperado

Un texto breve (5 a 10 líneas) que responde las tres preguntas con un ejemplo propio,
sin limitarse a repetir la definición de memoria.

## Restricciones

- No hace falta usar comandos de Git para este ejercicio.
- El ejemplo debe ser propio, no el mismo que aparece en el material de la clase.

## Resultados de aprendizaje

- RA-1: Comprender qué es el control de versiones y por qué es importante en el
  desarrollo de software.
