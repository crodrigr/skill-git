# Intermedio 02 — Navegación del historial

## Estado inicial

El repositorio del ejercicio Intermedio 01 (o cualquier repositorio propio con al
menos 3 commits).

## Proceso esperado

1. Ejecutar `git log` y revisar los tres (o más) commits del historial.
2. Elegir el commit más antiguo y, usando `git show` con su identificador o con
   `HEAD~N`, consultar su detalle.
3. Escribir, con tus propias palabras, qué cambió en ese commit (qué archivo, qué
   contenido se agregó).

## Resultado esperado

- `git log` muestra los commits en orden, del más reciente al más antiguo.
- `git show` sobre el commit elegido muestra el archivo y el contenido agregado en
  ese commit específico.
- Una descripción propia y correcta de qué cambió en ese commit.

## Restricciones

- No modifiques el repositorio durante este ejercicio: `git log` y `git show` son de
  solo lectura.

## Resultados de aprendizaje

- RA-6: Crear y manejar commits, y navegar entre ellos.
